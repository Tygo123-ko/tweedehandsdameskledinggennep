# Vera's Boutique Delight

💕 Prompt voor Lovable.dev

Maak een moderne, warme en gebruiksvriendelijke website voor een tweedehands dameskledingwinkel genaamd Vera's Boutique, gevestigd in Gennep, Nederland.

Doelgroep

De website is voornamelijk bedoeld voor oudere vrouwen (50+). Het design moet daarom:

Rustig en overzichtelijk zijn.

Grote, goed leesbare teksten gebruiken.

Eenvoudige navigatie hebben.

Warm, vertrouwd en persoonlijk aanvoelen.

Niet te modern of druk zijn.

Huisstijl

Gebruik de volgende kleuren:

🤍 Wit (#FFFFFF)

🌸 Zacht Roze (#F7D6E5)

🌿 Baby Groen (#D8EFD3)

🩶 Licht Grijs (#F3F3F3)

De uitstraling moet vriendelijk, elegant en gezellig zijn. Denk aan een sfeervolle boetiek waar klanten rustig kunnen rondkijken.

Gebruik afgeronde hoeken, zachte schaduwen en subtiele animaties.

Lettertypes

Gebruik een combinatie van:

Playfair Display voor titels.

Poppins of Open Sans voor de normale tekst.
